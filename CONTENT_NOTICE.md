# V3 — Banco de 600 preguntas

El archivo `questions.js` contiene 600 preguntas: 564 transcritas del PDF suministrado y 36 suplementarias originales.

## Derechos de autor
Las 564 preguntas transcritas proceden de una obra publicada y protegida por copyright. Esta versión debe considerarse para **estudio privado o uso autorizado**. No publiques el banco del libro en un repositorio público de GitHub a menos que tengas una licencia o autorización que permita su redistribución.

Si no tienes autorización para redistribuirlo, puedes conservar esta versión localmente y publicar una versión que contenga únicamente preguntas originales.

## Agregar preguntas
Desde `Question Bank` → `+ Add question` puedes crear preguntas de 3 a 7 opciones (A–G). También puedes importar/exportar JSON.
